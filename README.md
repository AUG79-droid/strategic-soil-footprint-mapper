# Strategic Soil & Footprint Mapper

Standalone browser-based training simulator for In-Service / Base Operations.

## Run locally
Open `index.html` in a modern browser. No build step, server or external JavaScript libraries are required.

## Training flow
1. Welcome
2. How to play
3. Five tactical missions
4. Consequence screen after each decision
5. Theory checkpoint after each mission
6. Final environmental audit and decision log

## Core topics
- Soil compaction and repeated loading
- Infiltration, runoff and erosion
- Drainage continuity
- Temporary operational footprints
- Microhabitat / edge disturbance
- Environmental operational control
- Mission-readiness trade-offs
- Audit evidence and improvement

## Notes
The scenarios are generic and educational. They are not site-specific procedures or engineering instructions.
